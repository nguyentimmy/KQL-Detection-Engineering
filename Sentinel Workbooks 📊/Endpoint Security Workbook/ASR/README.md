## 🛡️ ASR Detections

Native attack surface reduction hits across the fleet. The layer that shows what Defender already blocked.
Panels covering blocked techniques by rule, by device, and by frequency — designed to catch drift, not to investigate individually.

🎯 Purpose

This section tracks ASR rule firings estate-wide — a spike in a specific rule usually means either a new attack pattern or a legitimate tool that needs an exception, not an active incident on its own.

It's a signal source, not a triage queue. Repeated hits on one device become the trigger to check Endpoint Hunts or open Device Compromise Triage.
